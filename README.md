# 玄英的个人网站

玄英的个人成长记录网站首页。

这里会长期记录个人成长感悟、大学生活、阅读、AI 学习与英语练习。网站不是简历页，也不试图呈现一条已经确定的职业道路，而是一份持续更新的成长档案。

## 本地运行

无需安装依赖，直接使用浏览器打开 `index.html` 即可。

也可以在当前目录启动一个静态服务器：

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 技术说明

- 原生 HTML、CSS、JavaScript
- 单文件页面，无第三方依赖
- 响应式布局
- 支持文章主题筛选
- 尊重 `prefers-reduced-motion`
